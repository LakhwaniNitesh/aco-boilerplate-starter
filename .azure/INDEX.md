## 🎓 Key Concepts Explained

### The 3-Layer Model
```
EDS Storefront (Your UI)
     ↓ REST API
Adobe I/O Runtime (Middleware)
     ↓ HTTP/REST
HCL Commerce (Backend)
```

### Why This Architecture?
- **Security:** Credentials hidden server-side
- **Scalability:** Easy to add more services
- **Maintainability:** Each layer has clear responsibility
- **Testability:** Can test each layer independently

### API Contract
You don't implement HCL APIs directly. Instead:
1. Integration Agent builds REST endpoints
2. Your storefront calls those endpoints
3. Integration Agent handles HCL complexity

### Expected Workflow
```
1. User clicks "Add to Cart" on PDP
2. Your JS calls POST /api/hcl/cart/add
3. Integration Agent calls HCL API
4. HCL returns order confirmation
5. Your JS updates mini-cart display
```
